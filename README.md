# YomiShelf Windows downloads

Official website: https://yomishelf.pages.dev/

This repository distributes the Free and Premium Windows installers and release documentation. The development source is maintained separately.

Both installers include Python. They are unsigned. The Windows 10 laptop checks and automated Windows installation, upgrade, uninstall, highlighting and save-on-close checks have passed. Windows 11 is expected to work on 64-bit Intel/AMD PCs but has not been manually verified. No Mac/mobile/ARM release is supplied.

Use the release assets for installers and SHA-256 checksums. Third-party component licences and notices are included in the installed application. Product access, purchase availability and customer terms are described on the website. Premium requires a valid licence; no activated licence or personal reading library is bundled.

Back up your library before upgrading. Uninstall preserves your local data. Windows may show a publisher/security warning for the unsigned installers; keep Windows protection enabled.
